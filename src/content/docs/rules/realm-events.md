---
title: Realm Events
description: A description of the different events that can occur in each realm.
---

One realm event is rolled for each realm at the end of each turn. These events can increase or decrease stats, require checks, or inflict horrible events such as famine or family deaths.

# Roll d100

- 1: Treachery
- 2: Assassination
- 3: Uprising
- 4: Royal Council
- 5: Royal Writ
- 6: Earthquake
- 7: Plague
- 8: Famine
- 9: Fire
- 10: Revolt
- 11: Escape
- 12: Personal Tragedy
- 13: New Rival
- 14: Raid
- 15: Feud
- 16: Crime
- 17: Storm
- 18: Outlaws
- 19: Justice
- 20: Trade Dispute
- 21: Trade Surplus
- 22: Holiday
- 23: Celebration
- 24: Bounty
- 25: Supernatural Event
- 26-100: Nothing of Note
